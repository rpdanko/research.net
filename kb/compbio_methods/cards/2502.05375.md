problem: >
  For a discounted finite Markov decision process, value iteration eventually
  starts producing only optimal policies after some number of iterations, the
  turnpike integer. As a function of the discount factor this turnpike function
  governs the true complexity of value iteration, yet its structure (continuity,
  boundedness, piecewise behavior) near the discount factors where the optimal
  policy set changes is only partly understood. What are its properties, and can
  the problematic discount factors be detected efficiently?
setting: >
  Discrete-time MDPs with finite state and action sets, infinite-horizon expected
  total discounted reward, discount factor alpha in [0,1). Terminal rewards are not
  assumed zero (a generalization over prior work). Analysis is exact and
  combinatorial; complexity is measured as strongly polynomial (arithmetic-operation
  count independent of the magnitude of the data).
method: >
  Classify discount factors as regular or irregular (break points and touching
  points) via comparisons of finite-step transition probabilities between
  deterministic policies, which can be done in strongly polynomial time. On
  intervals free of irregular points, analyze the turnpike function using the
  analyticity of value functions there, proving upper semicontinuity and a
  boundedness/finite-partition equivalence. For small discount factors, bound the
  turnpike function by the number of states and build a value-iteration-based
  strongly polynomial solver valid for all sufficiently small alpha.

  A strongly polynomial algorithm to test whether a discount factor is irregular;
  a proof that the turnpike function is upper semicontinuous on each partition

  subintervals if and only if the turnpike function is bounded there; sufficient
  conditions for boundedness near irregular points (with a counterexample showing
  the known necessary conditions are not sufficient); and a proof that for small
  discount factors the turnpike function is bounded by the number of states, giving
  a strongly polynomial value-iteration solver for all small discount factors.

# Turnpike functions for discounted finite MDPs

Structural analysis of the turnpike function, the iteration count past which value
iteration produces only optimal policies, as a function of the discount factor. A
strongly polynomial test for whether a discount factor is irregular (where the
optimal policy set changes); upper semicontinuity and a boundedness/finite-partition
equivalence on regular intervals; sufficient (not necessary) boundedness conditions
near irregular points; and a proof that for small discount factors the turnpike
function is bounded by the number of states, yielding a strongly polynomial solver
there. Finite state and action sets throughout.
