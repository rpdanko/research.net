problem: >
  Data re-uploading makes even a single-qubit circuit a universal function
  approximator for classical inputs by repeatedly encoding features into trainable
  gates. When the input is a quantum state rather than classical numbers, its
  "values" are not available to plug into gate parameters. How can quantum data be
  re-uploaded so that a small circuit still gives a universal approximator of
  functions of the input state?
setting: >
  Quantum machine learning with quantum inputs: the data is an arbitrary (possibly
  multi-qubit) density matrix, available as multiple fresh copies. The processing
  register is a single ancilla qubit; readout is single-qubit measurement. Target
  functions are bounded continuous functions of the input state. Analysis is an
  expressivity / approximation-theory argument, not an empirical benchmark.
method: >
  A sequential architecture: the ancilla qubit is entangled with a fresh copy of
  the input state via a trainable unitary, the input register is then discarded and
  reset to a new copy, and the ancilla proceeds unmeasured to the next layer.
  Alternating trainable entangling unitaries with mid-circuit resets realizes a
  discrete cascade of completely positive trace-preserving maps on the ancilla,
  structurally a collision model from open-quantum-system dynamics. Universality is
  shown by constructing polynomial transformations of the input observables and
  invoking density of polynomials in the continuous functions.
contribution: >
  A quantum-input re-uploading architecture proved to approximate any bounded
  continuous function of an arbitrary input state using only one ancilla qubit and
  single-qubit measurements, with qubit count independent of the number of layers
  (via reset-and-reuse), and an explicit identification of the construction with a
  collision-model cascade of CPTP maps.

# Quantum data re-uploading as a universal approximator for quantum inputs

An architecture where a single ancilla qubit is repeatedly entangled with fresh
copies of an arbitrary input quantum state, with mid-circuit reset of the input
register between layers, realizing a collision-model cascade of CPTP maps on the
ancilla. Proved to approximate any bounded continuous function of the input state
using one ancilla and single-qubit measurements, with qubit count independent of
depth. Expressivity result only: no rate, sample-complexity, or trainability
guarantee. Quantum-ML-specific; carded for the universal-approximation property.
