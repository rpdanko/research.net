problem: >
  Doubly robust estimators of linear functionals of a regression function (e.g. average
  treatment effects) are consistent if either nuisance function is consistent, but
  asymptotic normality and valid confidence intervals typically require both nuisances
  to converge fast enough. Can inference be made doubly robust as well — asymptotically
  normal when only one nuisance is well estimated and the other converges arbitrarily
  slowly or is inconsistent?
setting: >
  Semiparametric estimation of linear functionals of the outcome regression (a subclass
  of mixed-bias parameters), with black-box / machine-learning nuisance estimators.
  Cross-fitting is used. Two nuisances: the outcome regression and the Riesz
  representer of the functional. Asymptotics: n to infinity, learner-agnostic rates; the
  key structural assumption is an asymptotic partial orthogonality condition. Evaluated
  on semi-synthetic benchmark datasets.
method: >
  Calibrated debiased machine learning (calibrated DML): standard cross-fitted DML is
  augmented by calibrating each cross-fitted nuisance estimate with an isotonic
  regression adjustment, so the calibrated nuisances satisfy a set of calibration score
  equations. Under partial orthogonality this makes the one-step / DML estimator
  asymptotically normal when either the regression function or the Riesz representer is
  estimated at a sufficient rate, regardless of the other. A bootstrap-assisted
  procedure builds confidence intervals without estimating further nuisances.
contribution: >
  Shows that calibrating the nuisance estimators inside a doubly robust procedure
  upgrades double robustness of consistency to double robustness of asymptotic
  normality: under an asymptotic partial orthogonality condition the calibrated DML
  estimator is root-n normal if either nuisance is estimated well enough, the other
  being allowed to be inconsistent. Provides an isotonic-regression implementation
  (a few lines added to existing DML pipelines), a bootstrap for confidence intervals,
  and an affirmative answer to a standing open question on learner-agnostic doubly
  robust inference.

# Doubly Robust Inference via Calibration

Semiparametric causal-inference paper. Introduces calibrated debiased machine learning:
adding an isotonic-regression calibration of cross-fitted nuisance estimates makes the
DML estimator of a linear functional asymptotically normal when only one of the two
nuisances (outcome regression or Riesz representer) is estimated well, provided an
asymptotic partial orthogonality condition holds. A bootstrap gives confidence intervals
with no extra nuisance estimation. Answers an open question on learner-agnostic doubly
robust inference. Intro not in extract but abstract + conclusion are detailed; high
confidence on the core claims.
