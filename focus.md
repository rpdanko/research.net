# Current focus

**Your handwriting. Agent-denied for writes (`settings.json`). Read by `math-scout` and `bridge-finder` every weekly run.**

This file is not a charter. The charters say what each knowledge base is *for* and should move slowly — everything downstream inherits them, and a charter that changes weekly makes the triage eval meaningless. This file says what you are thinking about *right now*, and it is supposed to be volatile.

The distinction matters to the agents and is stated in their prompts: charters define the search space, this file weights it. Nothing here can admit a paper the charters exclude, and nothing here can kill a bridge that would otherwise have been proposed. It reorders; it does not gate. That limit is deliberate — a live-state channel that could gate would let a bad week quietly narrow the system, which is the failure this whole file exists to prevent the *static* version of.

Rewrite it whenever it stops being true. Empty is a legitimate state: delete the contents below the rule and the agents will fall back to the charters alone, which is exactly the behaviour the system had before this file existed.

Keep it under half a page. If it is longer, it is a charter and belongs in `charters/`.
